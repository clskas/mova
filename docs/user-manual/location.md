# SENGA Location (portail partenaire)

Portail web du partenaire location (loueur entreprise ou particulier).

## Connexion et PIN

1. Ouvrez le portail et saisissez votre numéro **+243**.
2. Validez le code SMS.
3. Complétez **Mon dossier** (entreprise : RCCM, NIF, statuts ; particulier : pièce et adresse).
4. Après **Approuver** dans l'admin KYC, un **PIN à 6 chiffres** est envoyé par SMS et/ou e-mail.
5. Si le message n'arrive pas, l'équipe SENGA le renvoie depuis **KYC** ou **Utilisateurs**.

## Manuel dans le portail

**Aide → Manuel utilisateur**, ou le menu **Manuel utilisateur**.

## Exploitation

- **Véhicules** : ajouter chaque voiture (papiers + photo) après validation du dossier.
- **Réservations** : confirmer ou refuser.
- **Revenus** : gains en CDF.
