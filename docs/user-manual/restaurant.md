# SENGA Restaurant (portail partenaire)

Portail web : [restaurant.afri-soft.com](https://restaurant.afri-soft.com)

## Connexion et PIN

1. Ouvrez le portail et saisissez votre numéro **+243**.
2. Validez le code SMS.
3. Complétez **Mon dossier** (justificatifs). Tant que SENGA n'a pas validé, vous ne pouvez pas vendre.
4. Après **Approuver** dans l'admin KYC, un **PIN à 6 chiffres** est envoyé par SMS et/ou e-mail. Il sert à rouvrir le portail.
5. Si le message n'arrive pas, l'équipe SENGA le renvoie depuis **KYC** ou **Utilisateurs** (le PIN s'affiche une fois à l'écran admin).

## Manuel dans le portail

**Aide → Manuel utilisateur**, ou le menu **Manuel utilisateur**.

## Exploitation

- **Menu** : plats et prix en CDF après validation du dossier.
- **Commandes** : préparer, suivre, accepter.
- **Paramètres** : livreurs SENGA, internes ou mixte ; localisation.
- **Revenus** : encaissements en CDF.

Vous êtes payé à l'enlèvement du plat. Un livreur SENGA est payé après le PIN client.
