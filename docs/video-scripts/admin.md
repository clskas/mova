# SENGA Admin

| | |
|---|---|
| **Durée** | ~45 s (max 60 s) |
| **Langue** | Français, ton Kinshasa / RDC |
| **URL** | https://admin.afri-soft.com |
| **Parcours** | Tableau de bord → validation partenaire (KYC) |
| **Format** | 16:9 desktop |

Prérequis : rôle **ADMIN** ou **SUPER_ADMIN** (ou **SUPPORT** pour KYC). Menu : **Tableau de bord** (raccourci **Accueil**), **Utilisateurs**, **Chauffeurs**, **KYC**, **Courses**, **Restaurants**, **Catalogue location**, etc. Ne pas filmer **JWT dev**.

## Plan de tournage

| # | Durée | Écran (libellés UI) | Super | Voix off |
|---|-------|---------------------|-------|----------|
| 1 | 12 s | **Tableau de bord** — sous-titre *Kinshasa · couverture nationale*. KPI : **Utilisateurs**, **Chauffeurs en ligne**, **KYC en attente**, **Courses actives**, **Revenus du jour**. Lien rapide **Valider KYC** | Tableau de bord | La console SENGA : courses, chauffeurs, revenus. |
| 2 | 6 s | Cliquer **KYC en attente** ou **Valider KYC**. Titre **KYC**, sous-titre *Validation des documents chauffeurs* | KYC | Les nouveaux chauffeurs passent par le KYC. |
| 3 | 14 s | Une ligne en attente. Ouvrir un document si utile (2 s). **Approuver** (pas Refuser). Ne pas lire le PIN à voix haute ; flouter l’alerte *Code PIN d'activation chauffeur* | Approuver | Vous vérifiez les papiers, puis Approuver. |
| 4 | 6 s | Retour **Tableau de bord** : **KYC en attente** diminue, ou **Chauffeurs en ligne** | Partenaire validé | Le chauffeur peut passer En ligne. |
| 5 | 6 s | Carte de fin | admin.afri-soft.com | Admin SENGA — équipe interne. |

**Total : ~44 s**

Variante (si file KYC vide) : **Tableau de bord** (12 s) → **Catalogue location** → **Approuver** / **Refuser** un véhicule (14 s) → retour dashboard. Même durée. Ne pas enchaîner KYC + catalogue.
