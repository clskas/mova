# SENGA Web — PWA passager

| | |
|---|---|
| **Durée** | ~45 s (max 60 s) |
| **Langue** | Français, ton Kinshasa / RDC |
| **URL** | https://senga.afri-soft.com |
| **Parcours** | Choisir un service → commander un taxi |
| **Format** | 16:9 navigateur, ou 9:16 fenêtre étroite (PWA téléphone) |

Prérequis : déjà connecté (éviter **SENGA — Connexion** / **Recevoir le code** / **Se connecter**). En-tête : **SENGA — RDC**, *Kinshasa · Mobilité nationwide*.

## Plan de tournage

| # | Durée | Écran (libellés UI) | Super | Voix off |
|---|-------|---------------------|-------|----------|
| 1 | 6 s | Accueil. Accroche *La mobilité, simplement.* Grille : **Taxi / Moto-taxi**, **Livraison colis**, **Express**, **Repas**, **Déménagement**, **Location**, **Commissions**, **Portefeuille**, **Planifiée**, **Covoiturage**, **Historique** | SENGA sur le web | Sur senga.afri-soft.com, tous les services SENGA. |
| 2 | 6 s | Cliquer **Taxi / Moto-taxi** (*Course immédiate*). Titre **Taxi / Moto-taxi** | Taxi / Moto-taxi | Choisissez Taxi / Moto-taxi. |
| 3 | 10 s | Champ **Destination** (*Ex: Gombe, Limete, Masina…*). Saisir **Limete**. Type : **Moto-taxi**, **Standard**, **Confort** | Destination | Tapez Limete, puis le type de véhicule. |
| 4 | 8 s | **Estimer le prix** → bloc **Estimation** (CDF). Puis **Confirmer la course** | Estimer, puis confirmer | Estimez le prix, puis confirmez la course. |
| 5 | 8 s | Écran **Course confirmée** — *Un chauffeur sera assigné sous peu.* Lien **← Accueil** | Course confirmée | C’est confirmé. Un chauffeur arrive. |
| 6 | 6 s | Carte de fin | senga.afri-soft.com | SENGA, aussi sur le téléphone dans le navigateur. |

**Total : ~44 s**

Variante 15 s (si besoin d’un second clip) : accueil → **Repas** → un restaurant → **Commander**. Ne pas mélanger avec le taxi dans la même vidéo.
